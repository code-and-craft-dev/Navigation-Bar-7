# Sliding Expanding Pill Navigation (Masterpiece Edition)

A luxury, physics-driven floating bottom navigation dock featuring 5 balanced tabs, liquid elastic stretch physics, layered glass optics, kinetic icon micro-choreography, electric dual-tone gradients, and dynamic ambient dock bloom.

## ✨ Masterpiece Features
- 🌈 **Electric Dual-Tone Gradients**: Each tab is illuminated with a high-contrast modern gradient and matching ambient underglow:
  - 🏠 **Home**: Electric Cobalt Blue `linear-gradient(135deg, #0284c7, #2563eb)`
  - 🔍 **Search**: Sunset Amber Orange `linear-gradient(135deg, #ea580c, #f97316)`
  - ❤️ **Saved**: Neon Rose Crimson `linear-gradient(135deg, #e11d48, #f43f5e)`
  - 📊 **Stats**: Cyber Emerald Green `linear-gradient(135deg, #059669, #10b981)`
  - 👤 **Profile**: Royal Purple Fuchsia `linear-gradient(135deg, #9333ea, #c026d3)`
- 💎 **Layered Glass Optics**: The pill features physical light refraction — top specular glare (`inset 0 1.2px 1.5px rgba(255,255,255,0.45)`), subsurface depth (`inset 0 -1.5px 2px rgba(0,0,0,0.18)`), and dual-tier ambient colored shadows.
- 🎬 **Kinetic Icon Micro-Choreography**: Each icon has a custom activation personality:
  - 🏠 **Home**: Roof bounce & spring recoil (`spring-home`)
  - 🔍 **Search**: 16° rotational search tilt pulse (`tilt-search`)
  - ❤️ **Saved**: Organic double-beat pulse pop (`beat-heart`)
  - 📊 **Stats**: Vertical bar wave equalizer motion (`wave-stats`)
  - 👤 **Profile**: Nod & badge elevation spring (`nod-profile`)
- ✍️ **Kinetic Typography**: Text enters with an editorial baseline spring (`translateY(4px) → 0`) and tracking snap (`-0.4px → +0.2px`).
- 🧪 **Liquid Elastic Stretch**: Features volume-preserving stretch physics (`scale(stretch, 1 / sqrt(stretch))`) that stretches horizontally and pinches vertically in motion before snapping into place.
- 📐 **Zero-Jitter Dock Geometry**: Mathematical width-preservation keeps the dock rock-solid at 368px.
